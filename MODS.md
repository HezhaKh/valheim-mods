## Recording versions
The exact loaded version of each plugin is printed on every launch in
`<game>/BepInEx/LogOutput.log` — look for lines like `Loading [ValheimPlus x.y.z]`.
Jot them next to each mod above when you update, so future-you knows what worked.

## Notes
- On a multiplayer server, every player must run the same mods/versions (ValheimPlus especially).
- `winhttp.dll` is the Windows loader — ignored on macOS, kept only for portability.
